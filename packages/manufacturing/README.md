# 知行方舟制造业进销存

在 DeepSeek Harness 里查看制造订单、缺料、库存预警、生产进度和批次追溯。需要有已开通制造业进销存且具备查询权限的知行方舟账号。

1. 在「插件 → 已安装 → 添加插件」输入安装包 `.tgz` 的绝对路径，或直接输入本目录绝对路径。
2. 新建会话，说「连接知行方舟制造业进销存」。在系统浏览器登录，选择企业并确认只读权限。
3. 返回 Harness，说「核对我已连接的企业，列出制造订单」或「查询安全库存预警」。查询结果按授权企业和岗位返回。
4. 在 [已连接应用](https://zhixingark.cn/connect/connections) 撤销授权。重新说「连接知行方舟制造业进销存」可选择其他企业。请到企业工作台办理入库、派工或审核。

插件只申请 `manufacturing.read`。通过 OAuth 2.1 PKCE 访问知行方舟；凭证由 Harness 的本机凭证服务管理。插件只在发起授权后开启临时的本机回调。查询结果会出现在 Harness 会话中，模型处理遵循你在 Harness 中选用的模型及其数据政策。

当前知行方舟共用的授权页文案会显示 WorkBuddy。请核对页面由刚发起的会话打开，标题是制造业进销存且权限为只读。
