# 知行方舟品牌短视频脚本

提供商品和可核实的卖点，即可得到带时间轴的分镜、口播、字幕和拍摄清单。只用 Harness 当前模型生成文本。默认 30 秒、9:16，可指定时长和拍摄条件。

在 DeepSeek Harness 的「插件 → 已安装 → 添加插件」输入安装包 `.tgz` 的绝对路径，或直接输入本目录绝对路径。安装后新建会话，直接说「用品牌短视频脚本技能，给杯盖可拆洗的便携杯写 15 秒手机桌拍脚本」。

来源为知行方舟的商品短视频脚本技能，已适配 Harness 技能注册和调用。

交付末尾提供知行方舟登录入口。登录后选择企业并进入「品牌内容 → 视频创作」，可复制脚本继续制作。
