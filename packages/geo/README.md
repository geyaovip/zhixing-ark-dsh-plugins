# 知行方舟GEO 品牌可见度

查询已授权品牌项目和已有 GEO 报告，解读样本、评分、竞品与引用。需要在知行方舟开通相应应用，并有查询权限。

1. 在 DeepSeek Harness 打开「插件 → 已安装 → 添加插件」，粘贴 [1.1.0 安装链接](https://github.com/geyaovip/zhixing-ark-dsh-plugins/releases/download/business-v1.1.0/dsh-plugin-zhixing-ark-geo-1.1.0.tgz)，或选择已下载的压缩包。安装后启用插件。
2. 在会话中说「连接知行方舟 GEO」。浏览器打开后核对发起的应用，选择企业并确认只读权限。授权页显示发起客户端、企业和当前应用的只读访问范围。
3. 返回 Harness，说「总结这个品牌最新一份 GEO 报告」，或请插件打开工作台。启动分析、复测及下载报告请进入 GEO 工作台。

插件申请 `geo.read`，查询结果取决于企业和岗位权限。凭证由 Harness 的本机凭证服务管理，授权可在[知行方舟已连接应用](https://zhixingark.cn/connect/connections)撤销。工具结果进入 Harness 会话，由当前选用的模型处理。

## 需要写入记录时

在会话中明确要求开通当前应用的记录提案权限，在浏览器勾选授权。先查询真实记录，再让插件准备新增、修改或删除提案。打开提案确认页核对并亲自确认。返回 Harness 查询操作状态和业务回执。
